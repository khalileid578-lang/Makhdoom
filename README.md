# نظام إدارة كنيسة العذراء مريم — خدمة الأنبا أثناسيوس الرسول (اجتماع إعدادي)

نظام كامل لإدارة المخدومين والخدام، الحضور والغياب، والتقارير، ببيانات محفوظة على السيرفر (SQLite) وتسجيل دخول آمن بجلسات (Sessions) — بدون أي بيانات في localStorage.

## الصلاحيات
- **أدمن**: تحكم كامل + إدارة المستخدمين.
- **أمين خدمة**: إدارة المخدومين والخدام + الحضور والغياب + التقارير.
- **خادم**: يشوف المخدومين المسندين له فقط ويسجل حضورهم.
- **المخدوم**: لا يوجد له تسجيل دخول نهائيًا.

## 1) التجربة على جهازك (اختياري)
يحتاج تثبيت [Node.js](https://nodejs.org) (نسخة 18 أو أحدث).

```bash
cd church-app
npm install
npm run seed      # ينشئ قاعدة البيانات وحساب الأدمن الافتراضي
npm start
```
افتح المتصفح على: http://localhost:3000

**حساب الأدمن الافتراضي:**
- اسم المستخدم: `admin`
- كلمة المرور: `admin123`
⚠️ **غيّر كلمة المرور فورًا** من تبويب "المستخدمين" بعد أول دخول.

## 2) النشر المجاني على Render (خطوة بخطوة)

### الخطوة 1: ارفع الكود على GitHub
1. اعمل حساب مجاني على github.com لو مفيش عندك.
2. اعمل Repository جديد (خاص أو عام) وارفع عليه محتوى مجلد `church-app` بالكامل.
   - أسهل طريقة: من صفحة الـ Repository اضغط "Add file → Upload files" واسحب كل الملفات.

### الخطوة 2: اعمل حساب على Render
1. روح لـ https://render.com وسجل حساب مجاني (تقدر تسجل بحساب GitHub مباشرة).
2. اضغط **New +** → **Web Service**.
3. اختار الـ Repository اللي رفعته.

### الخطوة 3: إعدادات الخدمة
- **Name**: أي اسم (مثلاً church-app)
- **Region**: أقرب منطقة
- **Build Command**: `npm install && npm run seed`
- **Start Command**: `npm start`
- **Instance Type**: Free

### الخطوة 4: متغيرات البيئة (Environment)
من تبويب Environment أضف:
- `SESSION_SECRET` = أي نص عشوائي طويل وسري (مهم جدًا للأمان)
- `NODE_ENV` = `production`

### الخطوة 5: تخزين دائم للبيانات (مهم جدًا)
لأن قاعدة البيانات ملف SQLite، لازم تستخدم **Persistent Disk** حتى لا تُمسح البيانات عند كل إعادة تشغيل:
1. من صفحة الخدمة اذهب إلى **Disks** → **Add Disk**.
2. Mount Path: `/opt/render/project/src/db`
3. Size: 1GB (يكفي جدًا).

### الخطوة 6: Deploy
اضغط **Create Web Service** وانتظر دقيقتين. هتاخد رابط جاهز شكله:
`https://church-app-xxxx.onrender.com`

هذا هو رابط الموقع الجاهز للاستخدام. شاركه مع الأدمن وأمين الخدمة والخدام (كل واحد بحسابه الخاص من تبويب "المستخدمين").

## ملاحظات أمان
- كل كلمات المرور مشفّرة (bcrypt) ولا تُخزَّن كنص صريح.
- الجلسات محفوظة في قاعدة بيانات على السيرفر، وتنتهي تلقائيًا بعد 8 ساعات من عدم النشاط.
- في الخطة المجانية على Render قد "ينام" السيرفر بعد فترة عدم استخدام، وأول طلب بعدها ياخد ثواني ليستيقظ — هذا طبيعي في الخطة المجانية.
- للاستخدام الفعلي على نطاق أوسع، يُفضّل ترقية الخطة (Starter) لتفادي "النوم" والحصول على أداء أفضل.
